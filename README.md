# 我的导航 · Chrome 一键收藏

点击 Chrome 工具栏中的扩展图标，一键保存当前网页。扩展使用网页原有标题和网址，不翻译标题。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，启用右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本仓库根目录（包含 `manifest.json`）。
   如果使用 ZIP 包，先解压，再选择包含 `manifest.json` 的目录。
3. 在工具栏的扩展菜单中固定「我的导航 · 一键收藏」。
4. 打开一个普通网页，点击扩展。已有 Token 可直接登录；新用户点击「没有 Token？注册并生成」，填写导航名称。
   注册后自动登录并创建「我的收藏」分组。点击「复制 Token」另存备份，再点击「已备份，开始收藏」。
5. 打开要收藏的网页，点击「保存当前网页」。扩展自动使用上次成功保存的分组；首次使用时使用第一个分组。

这是可直接安装的本地版本，尚未提交 Chrome 网上应用店。更新代码后，在扩展管理页点击「重新加载」。

## 1.3 新功能

- 弹窗改为一键收藏，不显示语言、标题、网址和分组输入。网页标题保留原文；界面沿用已保存的语言偏好，否则跟随浏览器。
- 保存到上次使用的分组；若该分组不存在，使用第一个分组。可在导航网站创建和整理分组。

## 1.2 功能

- 支持中文和英文。
- 右键收藏网页或链接；Alt/Option + Shift + S 打开弹窗，可在 `chrome://extensions/shortcuts` 修改。
- 首次使用提示登录、备份和保存步骤。
- 只加载分组和当前 URL 的查重结果，保存由服务端原子去重。
- 网站提供 HTML/JSON 导入导出、30 天回收站与 35 天独立备份。
- Chrome 127 或更新版本；升级新增 `contextMenus` 权限，Chrome 可能要求确认。

## 行为

- 使用现有导航 API，每位用户只能访问自己 Token 对应的分组。
- 注册账号拥有自己导航的编辑权限，没有平台管理权限。生成的 Token 也能登录导航网站。
- 注册前会在本地保存随机重试凭据。网络中断或关闭弹窗后，点击「继续注册」可恢复同一个账号，不会重复创建。
- 登录后可随时点击「备份 Token」。Token 没有绑定邮箱，丢失后无法自助找回，请另存到可信位置。
- Token 存储在当前浏览器的 `chrome.storage.local`，不会通过 Chrome Sync 同步。
- 登录信息保留 99 年，直到退出、卸载或清除扩展数据；服务器撤销 Token 后仍会失效。
- 记住上次成功保存的分组，切换账号时清除该选择；无历史选择时使用第一个分组。
- 已存在的相同网址会提示所在分组，并停止重复写入。URL 查询参数和锚点保留。
- 保存时由服务端验证分组归属并原子检查重复 URL；双击不会产生并行请求。
- 保存由扩展后台执行。弹窗关闭后可重新打开查看；网络中断时会提示结果未确认，需要先刷新核对。
- 不支持 `chrome://`、本地文件、扩展页面及含用户名密码的网址。
- 没有分组时，先到导航网站创建分组。

## 权限与数据

使用 `contextMenus`（右键收藏）、`activeTab`（主动点击扩展时获取当前标签页标题和网址）、`storage`（保存登录与上次分组）和
`https://home-api.zhaoyouning.com/*`（导航 API）。不注入内容脚本，不读取浏览历史。
登录后打开弹窗时，会将当前网页网址发送到 API 查询是否已经收藏；标题和收藏写入只在点击保存后提交。请求携带用户自己的 Token。包内没有账号凭据。
退出账号会清除扩展本地数据，不会删除导航里的书签。

## 打包

执行 `npm run package`，生成 `dist/home-navigation-chrome-1.3.0.zip`；需要 Python 3，无需安装依赖。
执行 `npm test` 运行后台流程测试；需要 Node.js 20 或更高版本。
1.3 版本需要后端先应用增量迁移 `0007_library_tools.sql` 并部署轻量接口。注册功能还需要 `POST /api/auth/register` 及注册限流绑定。
新版后端以单条条件插入语句原子去重，并记录请求编号；升级后会保留历史已有重复数据，不擅自合并删除。
